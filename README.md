# 最強の名前トーナメント 管理ツール(仮称)

回答収集に絞った、依存ライブラリ・ビルド不要のブラウザツールです。

## 起動

ZIPを展開し、`index.html` をブラウザで開いてください。同じフォルダの `app.js`、`core.js`、`style.css` が必要です。スマートフォンではGitHub Pagesでの利用を推奨します。PythonがあるPCなら、このフォルダで `python3 -m http.server 8000` を実行し `http://localhost:8000` でも利用できます。

## GitHubに置く

1. リポジトリを作り、このフォルダの中身をアップロードします（ZIPそのものではなく展開したファイル）。
2. ブラウザで公開する場合はリポジトリの **Settings → Pages** からブランチのルートを公開対象に設定します。
3. 発行されたURLで開きます。サーバーやAPIキーの設定は不要です。

実回答、Discord ID、バックアップJSONはリポジトリに含めないでください。配布ソースには実回答を含めていません。ツールの利用者ごとのデータはそのブラウザ内にあり、Pagesを公開しても回答データが他の利用者に共有されるわけではありません。

## 使い方

1. 「大会を作成」で大会名を入力。1人あたりの上限を指定します（初期値3、0は無制限）。
2. Google SheetsのURLを入力して読込ボタンを押すか、CSVを読み込みます。
3. Discord ID・名前・「必殺技など」の対応列を確認します。入力例に合わせた初期列は「タイムスタンプ / discord ID / 新商品の名前 / 新商品のジャンル / 新商品の説明」です。
4. 回答数・上限超過・入力不備を確認します。
5. 見出し、カテゴリ名、項目名、連番、コードブロック、出力項目を設定し、生成されたメッセージをコピーしてDiscordに貼り付けます。

「デモを読み込む」で架空の回答5件を試せます。初期上限なら採用3件・上限超過1件・ID未入力1件です。

### Google Sheetsの読込

- 通常のスプレッドシートURLと「ウェブに公開」のURLを処理します。gid欄を指定するとURL内のgidより優先します。両方未指定なら0です。
- URL取得はログイン不要でGoogleからCSVを取得できる場合に限ります。アクセス権、CORS、公開設定などで失敗する場合があります。本ツールにはGoogleログイン機能はありません。
- 非公開シートはそのまま非公開で運用できます。Google Sheetsで対象タブを開き、**ファイル → ダウンロード → カンマ区切り形式 (.csv)** で取得し、ツールのCSV読込を使用してください。直接読込のために個人情報を公開する必要はありません。
- CSVはUTF-8、先頭行が列名、1行が1回答という形式です。セル内の改行・カンマ・二重引用符に対応します。
- 更新ボタン／CSV再読込は、その大会の回答一覧を現在の表で置き換えます。追記ではないため、同じ表の再読込で二重計上しません。読み込んだ表から消えた回答は本ツールでも消えます。
- 手動更新です。バックグラウンド自動取得・Formsへの書込みはありません。
- Googleのシート接続仕様の参考: https://developers.google.com/chart/interactive/docs/spreadsheets

### 上限のルール

- 大会ごと、Discord IDごとに集計します。IDの前後空白・先頭の@・英字の大小を統一し、数字のIDと `<@数字>` も同一視します。数字は文字列として保持します。
- ユーザー名と数値IDは別の値です。同一人物と判定するには入力形式を統一してください。可能なら不変の数値ユーザーIDを使います。
- CSV／シートの上から順に採用します。タイムスタンプの自動並び替えはありません。先着順で管理する場合は元の表の順序を維持してください。
- IDまたは名前が空欄の回答は採用しません。入力不備の行は上限枠を消費しません。IDごとの「全回答」には入力不備も含まれます。
- 上限超過の回答も一覧に残り、上限変更で再判定されます。同名回答は自動重複排除しません（別回答としてカウント）。
- Google Formsの送信自体を防ぐ機能・本人確認機能はありません。

### Discord整形

- 「必殺技など」は0〜5つの列を追加・削除できます。必殺技、属性、説明など任意の列を選びます。追加した順に名前の後へ出力します。
- 「『必殺技など』の項目を出力」でこれらの項目をまとめて表示・非表示にできます。「項目名を表示」で列名の表示を切り替えます。
- その他の出力項目はその後に元の列順で続きます。同じ列を二重に出力しません。
- コードブロックは回答1件ごとに、名前と選択した追加項目をまとめて囲みます。別の回答は別のコードブロックになります。スプレッドシートの1行を1件とし、同じ投稿者でも回答ごとに独立したメッセージ・コピー欄に出力します。コードブロックをオフにしても回答同士はまとめません。長い場合は1,900文字以内に分割し、各ブロックを閉じます。1回答だけで長すぎる場合は回答途中でも分割します。
- 見出しの `{大会名}` は大会名に置換します。見出しはプレーンテキストとして扱います。
- @にはゼロ幅スペースを入れ、入力されたメンションによる通知を抑制します。入力中のコードフェンスは無害化します。コードブロックをオフにすると入力のMarkdown記号をエスケープします。
- Discord自動送信・Webhook・Botはありません。出力をコピーして貼り付ける方式です。

## データの保存

同一ブラウザ・同一URLのlocalStorageに自動保存します。端末・ブラウザ間同期や管理者認証はありません。ブラウザデータ削除やプライベートモード終了で失われる場合があります。ローカルファイルの保存動作はブラウザに依存するため、継続利用は同じPages URLまたはローカルサーバーを推奨します。

「全大会をバックアップ」で回答・設定を含むJSONを保存できます。「復元」は全大会を置き換えるため確認ダイアログが出ます。保存エラー時も画面上のデータは保持します。バックアップには回答とIDが含まれます。

## 開発・検証

- `index.html`: 画面
- `style.css`: レスポンシブスタイル
- `app.js`: 大会管理、読込、保存、画面更新
- `core.js`: CSV・ID集計・Discord出力（ブラウザ／Node共通）
- `tests/core.test.cjs`: ロジックの回帰テスト

Node.jsで `npm test`（追加インストール不要）。CSVの改行・引用符、上限と未入力、カテゴリ表示、長いUnicode回答の分割、URL検証を確認しています。構文チェック済み。実ブラウザでの表示・クリップボード・実シートURL取得のエンドツーエンド検証は未実施です。

手動確認: デモ読込 → 上限1に変更 → 上限超過3件を確認 → 別大会の作成 → 大会切替 → 再読込 → バックアップ／復元 → Discordへの貼付を確認してください。

v0.2.2 / 収集機能のみ。対戦表・投票・勝敗管理は未実装です。


## v0.2.0への更新

同じGitHubリポジトリの `index.html`・`app.js`・`core.js` を新しいファイルで上書きしてください。更新前に全大会のバックアップを推奨します。以前の保存データとバックアップは読み込めます。旧「カテゴリの列」は「必殺技など」の最初の項目へ移行します。以前のカテゴリ値でのグループ分けは終了し、各回答の追加項目として出力します。
